# Assets Directory

Эта папка содержит все медиафайлы для проекта.

## 📁 Структура папок

- `images/` - Общие изображения (логотипы, иконки, диаграммы)
- `screenshots/` - Скриншоты интерфейсов и демонстрации работы

## 📸 Как добавить скриншот

1. **Сделайте скриншот** (например, Swagger UI)
2. **Сохраните файл** в соответствующую папку:
   - `screenshots/swagger-ui.png` - для Swagger UI
   - `screenshots/rag-response.png` - для примера ответа
   - `screenshots/api-demo.png` - для демо API
3. **Файл автоматически отобразится** в README.md

## 🎨 Рекомендации

- **Формат**: PNG или JPG для скриншотов, SVG для логотипов
- **Размер**: Не более 2MB на файл
- **Разрешение**: 1920x1080 или меньше для скриншотов
- **Названия**: Используйте kebab-case (например, `api-response-example.png`)

## 📝 Примеры использования в Markdown

```markdown
![Описание](./assets/screenshots/your-screenshot.png)
![Описание](./assets/images/your-image.png)
```

## 🔄 Git и изображения

Все файлы в этой папке будут включены в Git репозиторий и отображаться на GitHub/GitLab.
